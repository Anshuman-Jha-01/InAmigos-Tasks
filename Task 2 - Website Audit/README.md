# 📊 InAmigos Foundation Website Audit

**Site Reviewed:** [inamigosfoundation.org.in](https://inamigosfoundation.org.in)  
**Prepared:** August 2026  
**Author:** Anshuman Jha  

---

## 📌 Overview

This repository contains the **Website Improvement Analysis & Recommendations** for the InAmigos Foundation.  
The audit highlights **critical security issues, usability gaps, and trust-building opportunities** that directly affect donor confidence, volunteer engagement, and CSR partnerships.

---

## 🚨 Executive Summary

The site successfully presents the foundation’s credibility (80G/12A, CSR-1, NITI Aayog, ISO 9001:2015) and projects (Seva, Bachpanshala, Jeev, Udaan, Prakriti, Vikas).  
However, execution issues undermine trust:

- **Critical:** Spam/gambling links injected site-wide → indicates compromise.  
- **Critical:** Causes page is empty → no donation-driving content.  
- **High:** Volunteers’ personal Gmail addresses exposed publicly.  
- **High:** Social icons link to generic homepages (Twitter, Google, Pinterest).  
- **Medium:** Contact/Volunteer forms lack validation; Gallery lacks captions/alt text.  

---

## 🛠️ Key Findings

### 🔒 Security
- Gambling/spam links injected in global header.  
- CMS/plugins may be compromised.  
- Immediate malware scan and credential rotation required.

### 🎯 Content & UX
- Homepage carousel lacks a clear mission statement.  
- Donation button redirects to bare Razorpay link without context.  
- Causes page completely empty.  
- Volunteer directory exposes personal emails.  
- Blog/Events outdated (last updated Jan–Mar 2025).  
- Gallery images lack captions, alt text, and accessibility features.

### 📈 Trust & Transparency
- Certifications listed but not visually verified (no badges, numbers, or PDFs).  
- No annual report or financial transparency page.  
- Missing donor/volunteer testimonials.

## 📌 Recommendations

### Design & Layout
- Establish consistent visual hierarchy (headings, buttons, spacing).  
- Use real photography of fieldwork (feeding drives, tree planting, classes).  
- Ensure mobile responsiveness, especially for carousel and volunteer grid.

### Content & Trust
- Add **annual report** and **financial transparency** page.  
- Include donor/volunteer testimonials with consent.  
- Provide clear breakdown of **“Where your money goes.”**

### SEO & Technical
- Submit site for reconsideration in Google Search Console after cleanup.  
- Add meta descriptions and alt text sitewide.  
- Enable HTTPS security headers and schedule recurring malware scans.
