# InAmigos Foundation - Website

**InAmigos Foundation - Website** is a modern, responsive NGO website built using **HTML5** and **CSS3**. The website showcases the foundation's mission, social impact, ongoing projects, achievements, and opportunities for volunteering and donations. Designed with a clean, professional interface and responsive layout, the website effectively communicates the organization's vision of creating a compassionate and inclusive society.

## Project Overview

**InAmigos Foundation - Website** is a fully responsive NGO website developed to establish a strong digital presence for the organization. It highlights the foundation's vision, ongoing initiatives, impact statistics, gallery, government recognitions, and volunteer opportunities.

The website is designed with accessibility, readability, and responsiveness in mind. It features modern typography, engaging layouts, attractive color schemes, smooth hover effects, and optimized sections to provide visitors with an informative and visually appealing browsing experience.

---

## Features

* **Modern Landing Page**

  * Eye-catching hero section with call-to-action buttons.
  * Strong visual identity highlighting the foundation's mission.

* **About Section**

  * Introduces the organization, its vision, history, and objectives.
  * Displays important facts about the NGO.

* **Impact Statistics**

  * Highlights achievements through numerical statistics such as:

    * Trees Planted
    * Meals Distributed
    * Girls Empowered
    * Year Founded

* **Projects Showcase**

  * Dedicated cards for all major initiatives including:

    * Project Prakriti
    * Project Seva
    * Project Udaan
    * Project Jeev
    * Project Bachpanshala
    * Project Vikas

* **Social Impact Section**

  * Demonstrates how contributions support:

    * Food Drives
    * Social Work
    * Charity Programs
    * Cleanliness Campaigns

* **Gallery**

  * Responsive image gallery showcasing events and social initiatives.

* **Trust & Credentials**

  * Displays government registrations, certifications, CSR eligibility, ISO certification, NGO Darpan registration, and other recognitions.

* **Call-to-Action**

  * Encourages visitors to volunteer or support the organization.

* **Responsive Design**

  * Optimized for desktop, tablet, and mobile devices.
  * Adaptive layouts using CSS Grid and Flexbox.

* **Accessibility**

  * Semantic HTML structure.
  * Meaningful alt text for images.
  * Smooth scrolling navigation.

## Installation

### Prerequisites

You only need a modern web browser such as:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

### Steps

1. **Clone the repository**

```bash
git clone https://github.com/Anshuman-Jha-01/InAmigos-Tasks.git
cd Task 1 - NGO Awareness Webpage
```

2. **Open the project**

Simply open the `index.html` file in your browser.

Or use **VS Code Live Server**:

```bash
Right Click → Open with Live Server
```
